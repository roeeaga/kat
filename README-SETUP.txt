KAT website - setup (3 steps)

1) ORDERS + CONTACT FORM -> kat.orders.il@gmail.com (key already inserted - nothing to do)
   - Go to https://web3forms.com , enter the email where you want to receive orders, get the Access Key.
   - Open order.html and contact.html, search for PASTE_YOUR_WEB3FORMS_ACCESS_KEY_HERE and replace it with your key (once in each file).
   - Each order arrives as an English email with every detail. The logo file is NOT in the email: the customer is told to email it to kat.orders.il@gmail.com quoting the order number.

2) PUBLISH (free)
   - Cloudflare Pages / Netlify: drag-and-drop this folder. The _headers file applies the security headers.

3) BUSINESS EMAIL
   - The site now shows kat.orders.il@gmail.com. Later, with a domain, you can forward a professional address to it (Cloudflare Email Routing, free).
